# M05 · 三种植物独立成长素材

**当前游戏状态图：** [`assets/art/plants/`](../../../assets/art/plants/)。这些是共用成长状态，不等于三种植物各自独立的正式套图。**游戏内参考：** [乌龟花园截图](../../../art-production-kit/M05-plants/gameplay-reference/turtle-garden.jpg)。

每种植物至少包含种子、幼苗、成长、成熟/开花/结果、收获后五态；叶形、株型、花/果轮廓必须清楚不同。建议每态128×128或256×256 RGBA透明；根部锚点固定(64,116)或(128,232)；阶段过渡0.25–0.45秒，不需要逐态高帧循环。

**接入：** `assets/art/plants/<plant_id>/`、`assets/art/production-art.json`、`scripts/visual/scene_art_registry.gd`和`main.gd`种植绘制；状态继续使用已有存档字段保存种类/阶段。**验收：** 每类种植→浇水→成长→收获→再种；刷新前后状态一致；检查透明边缘和根部位置。

**提示词：**

> 以附件花圃截图和状态图为风格参考，设计三种轮廓明显不同的童话植物，独立叶形、枝干和花/果。每种输出种子、幼苗、成长、成熟开花/结果、收获后五阶段。柔和手绘绘本风，逐个植物独立透明RGBA；建议128×128或256×256，所有阶段根部锚点固定(64,116)或(128,232)。不要盆器、背景、投影、文字、不透明底色、彩边或仅靠同一造型换色区分。
