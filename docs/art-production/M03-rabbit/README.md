# M03 · 兔子待机、引导与回应

**原图：** [rabbit.png](../../../assets/art/characters/rabbit.png)（536×594 RGBA）。**游戏内参考：** [生活岛地图截图](../../../art-production-kit/M03-rabbit/gameplay-reference/life-island-map.jpg)。

保留兔子耳朵、脸、毛色、衣物（若原图有）、身材比例和绘本质感；回应时朝向玩家。四向待机每向2–4帧；引导/打招呼4–6帧；任务完成开心动作4–6帧。逐帧512×512 RGBA透明，脚底锚点(256,440)，边缘≥24px，建议8 FPS，不烘焙地面阴影。

**接入：** `assets/art/characters/rabbit/`、`assets/art/production-art.json`、`scripts/boot/main.gd`兔子引导/回应分支。**验收：** 装饰后提示、靠近交互、回应和后续任务衔接均可见；不以静图缩放/弹跳冒充动作。

**提示词：**

> 依据附件兔子原图，保持脸部、耳形、颜色、衣物、绘本比例和柔和手绘质感。制作四向自然待机呼吸/眨眼、面向玩家的引导招手、回应点头/开心动作；待机2–4帧，回应4–6帧，8FPS。逐帧512×512透明RGBA，脚底锚点固定(256,440)，至少24px透明边缘，不要地面、投影、文字、拼图或整张图片上下弹跳。
