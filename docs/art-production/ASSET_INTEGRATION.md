# 外部 PNG 动画接入流程

## 目录和命名

- 单帧序列放在 `assets/art/characters/<character>/<state>_<direction>/`，如 `turtle/walk_down/000.png`。
- 静态替换资源放回当前 registry 所声明的类别目录；植物放 `assets/art/plants/<plant_id>/`，钓鱼新增物放 `assets/art/fishing/`。
- 帧名固定三位编号 `000.png` 起，禁止混用 atlas、序号跳帧或覆盖旧资源。候选资产先放 `assets/art/incoming/<batch>/`，验收通过后再迁入正式目录。
- 每个角色状态需附 `README.md`，记录来源、尺寸、锚点、方向、FPS、许可/作者与 SHA256。

## 图像规格

- PNG RGBA，透明背景；同一动画所有帧画布完全一致。
- 角色默认画布 512×512、脚底锚点 `(256,440)`；鸟可记录飞行偏移。植物默认 128×128 或 256×256，根部锚点按批次规格固定。
- 帧的主体不可裁切；每帧沿用统一锚点，不烘焙场景阴影，不用整体上下平移模拟动作。
- FPS 以批次 README 为准；除规格要求外，不擅自改逻辑显示尺寸或碰撞盒。

## Godot 导入和注册

1. 先在 `assets/art/incoming/<batch>/` 放入素材并核对透明通道、帧尺寸、帧序和锚点。
2. 保留当前正式 PNG 与 `.import` 元数据。Godot 导入设置使用 Filter/Repeat 与原资源一致；像素/手绘边缘不得私自换压缩或 mipmap 策略。
3. 更新 `assets/art/production-art.json` 和必要的 `assets/art/scene-art-manifest.json`，路径必须指向新资产；不直接删除旧条目。
4. 将帧注册到对应 `SpriteFrames` 或动画资源，连接当前角色状态机。只替换视觉层，不改角色节点位置、碰撞、任务状态、存档字段、输入或移动速度。
5. 新增导入规则/帧注册测试；逐状态运行无错误检查，再做手动地图视觉检查。

## 测试、验收和回退

- 先跑 Godot 全套回归，再验四方向、静止转向、快速/慢速移动、碰撞、互动、任务进度与刷新恢复。
- 录制同一角色替换前后短片；检查脚底锚点、遮挡、水边/门框穿插、透明边缘、动作循环和角色比例。
- 验收前保留旧图和旧注册项，使用清单记录新旧文件 SHA256。发生回归时只回退 registry/动画引用到旧资源，删除无引用新文件需在后续独立清理变更里处理。
- 美术替换不能改存档 schema，也不能把动画阶段写入任务存档；角色碰撞与游戏逻辑继续由原状态控制。

## 合并门槛

每批提交应附：素材来源与许可说明、文件清单、尺寸/锚点检查结果、导入日志、回归日志、桌面和手机横屏截图/录屏，以及可直接回退的旧资源路径。M01、M02先各自小批接入与验收，完成后再并行制作 M03–M06。
