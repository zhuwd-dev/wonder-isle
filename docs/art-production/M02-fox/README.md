# M02 · 狐狸待机、行走与自然出屋

**角色原图：** [fox.png](../../../assets/art/characters/fox.png)（445×615 RGBA）。**小屋原图：** [fox-cottage-complete.png](../../../assets/art/environment/fox-cottage-complete.png)。

**游戏内参考：** [生活岛地图截图](../../../art-production-kit/M02-fox/gameplay-reference/life-island-map.jpg)。

**保留：** 橘色毛发、尾尖、脸部特征、身形比例及小屋画风；门槛/门框的前后遮挡关系。

**制作规格：** 门内探头、跨门槛、四足走出、停步转向、打招呼至少5阶段；四向行走每向≥6帧，门口动作4–6帧。逐帧512×512 RGBA透明；脚底锚点(256,440)，边缘≥24px；出屋8 FPS，行走8–10 FPS；显示高度约85–100逻辑像素。

**接入：** `assets/art/characters/fox/`；更新 `assets/art/production-art.json`，接入 `scripts/boot/main.gd` 狐狸状态/动画。

**验收：** 靠近、离开、再次靠近、刷新；狐狸不闪现、不穿门槛、不重复消费任务状态；录屏看清门框遮挡及自然走出。

**可复制提示词：**

> 参考附件狐狸原图和小屋截图，保持同一只橘色狐狸、尾尖、眼睛、脸型与绘本质感。制作从门后探头、迈出门槛、沿小屋左前方草地四足走出、自然停下转向玩家并打招呼的连续动作。四方向各至少6帧行走，门口动作4–6帧。单帧512×512透明RGBA，脚底(256,440)固定、透明边缘至少24px；出屋8FPS，走路8–10FPS。禁止瞬移、静图平移、悬浮、穿墙、改变脸部与尾巴特征。
