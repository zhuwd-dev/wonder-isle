# 《奇趣小岛》项目文档包

版本：V1.0  
目标市场：中国大陆  
目标玩家：6—8 岁儿童  
开发资源：个人独立开发，AI 辅助  
阶段目标：低成本验证核心玩法，不直接承诺商业上线

## 文档目录

1. `01_立项说明书.md`：项目定位、市场假设、目标、范围、成本和立项决策门槛。
2. `02_游戏策划案_GDD.md`：核心玩法、世界设定、系统规则、内容范围、交互和验收标准。
3. `03_MVP开发规格与技术方案.md`：建议技术架构、目录结构、数据结构、任务/建造/存档方案及 MVP 验收清单。
4. `04_AI开发提示词.md`：可直接复制给 AI 编程工具的分阶段提示词，包含先审计、分阶段实现和禁止事项。
5. `05_测试与儿童安全清单.md`：试玩方案、功能测试、儿童隐私与大陆发行事项检查表。

## 使用建议

- 先阅读立项说明书，再确认 GDD 和 MVP 范围。
- 将这套文档放到游戏仓库的 `docs/` 目录。
- AI 开发时先发送 `04_AI开发提示词.md` 的“总控提示词”，然后每次只执行一个阶段提示词。
- 第一阶段只做本地可玩原型；没有完成试玩验证前，不接账号、云服务、广告、内购或社交。
- 文档中标注“假设/待验证”的内容不得直接写成市场事实。
- 任何商业发行、出版审批、未成年人保护和儿童个人信息处理要求，都应在正式发行前按当时有效规则向主管部门、平台或专业人士核实。

## 项目原则

1. 先验证玩法，再扩内容。
2. 所有核心玩法必须可离线完成。
3. 任务、物品和建造尽量配置化、复用化。
4. 不以强制签到、随机付费奖励、倒计时焦虑或社交压力驱动留存。
5. 任何对现有工程的修改都应先检查现状和用户改动，不盲目覆盖文件。
