# 儿童引导专项：实现与验收边界

- 桥梁：只在下侧入口朝对岸输入时作安全切向修正，所有子步仍经过真实碰撞；松开输入即停，不改变桥面边界或存档。浏览器用上下入口、两岸、20轮往返、摇杆和护栏验证。
- 角色：现有四方向状态控制器工作正常；正式28帧仍缺失，方向视觉和脚步动画 BLOCKED。静态旧立绘不旋转伪装正背面。
- 兔子：`scripts/game/island_guidance.gd` 只读选择任务。主动选择的布置/整理优先，否则按实际解锁顺序引导。气泡包含物品和目标图片，点击时短暂突出目标；不替玩家完成任务，不增加持久存档字段。桥完成后有一次轻量对话图形提示。
- 花圃：无种子、已种植或超出120世界单位不提示；120以内出现轮廓，76以内增强。效果取现有土壤贴图的alpha轮廓，中心透明，缓慢呼吸和淡出，不使用绿色矩形或纯几何圆环。
- 小屋：仅携带未交付木材时显示门前暖色轮廓，进入原88单位交互范围增强；使用木材与小屋图形关系、三枚木板图形进度和短暂施工反馈，删除常驻“建造中/交付x/3”文字。交付规则和库存逻辑不变。
- 植物：正式`assets/art/plants/seedling.png`仍缺，需128×128 RGBA、根部(64,116)，自然叶片和土壤融合、无裸根土球和大光晕。其他植物成长及奖励状态继续按production-art.json接入；现有程序植物只作降级，不能称作正式美术完成。

自动化可验证状态、输入、交付、存档和提示时机；截图检查可验证遮挡与视觉差异。尚无6～8岁儿童观察测试，不能据此宣布已证明儿童无需文字即可理解所有步骤。

## 实现位置与复查

- `scripts/game/island_guidance.gd`：只读任务优先级；`tests/test_child_guidance.gd`覆盖所有任务阶段、并行选择和重新开始时清除临时反馈。
- `scripts/boot/main.gd`：`_guidance_details`提供图标与目标位置，`_update_environment_focus`计算远近和完成后的淡出，`_draw_q004_area`绘制图形进度。
- `scripts/visual/ground_focus.gd`、`.gdshader`：共用贴图alpha遮罩，外扩绘制区域避免边缘裁切；轮廓内侧保持透明。材质使用显式遮罩纹理，兼容Godot的无图形回归和Web渲染。
- `tools/test_story_browser.py`：实际键盘走通种植和交付，截图比较无提示、接近、可操作、完成，并覆盖三种尺寸。
- `tools/test_art_browser.py`：实际按四方向键，检查移动状态并记录站立截图；可用`ART_VIDEO_DIR`录下当前真实效果。截图前先松键，避免截图开销造成额外移动；各方向通过真实输入回到开阔区后单独验证。静态降级立绘依然是静态，不据状态断言宣称真实动画通过。
- 浏览器截图分别在`/tmp/wonder-story-artifacts`及`tests/artifacts`；这些是本地验收产物，不提交到版本库。844×390目前无控件重叠，但固定画布缩放后的文字偏小，仍需下一批移动端可读性优化。
