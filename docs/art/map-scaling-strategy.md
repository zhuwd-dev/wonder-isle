# 地图缩放与高清资源方案

当前背景 `assets/art/environment/floating-garden-bg.jpg` 为 1280×720 的单层栅格图。它不是矢量图，没有已知的更高分辨率原图或可用分层；放大到超过原分辨率时会插值，不能宣称出现真实高清细节。批次 C 将最高倍率限制为 1.35 倍，降低模糊程度；宽屏适配也可能需要对原图插值或出现少量留边。

世界逻辑坐标仍为 1280×720。世界绘制和鼠标、触摸坐标共用相机变换；HUD、摇杆、材料托盘和交互按钮保留独立屏幕坐标。按钮缩放围绕玩家，滚轮围绕鼠标；空白世界区域支持双指缩放。放大后移动玩家时，相机在玩家接近视野边缘时缓慢调整；手动拖动地图仍可查看其他区域。重置按钮回到完整地图。

后续应先取得具有相同构图的原生高清原稿或授权分层源文件，再以世界坐标不变为前提替换背景，检查纹理大小、Web 下载量和低端设备的 GPU 内存。地图扩展可逐步引入独立区域及按需加载，按区域登记地面、前景和碰撞；不应为本次缩放重设任务坐标。若只能使用超分辨率处理，它只能作为有说明的过渡资源，不能称为恢复原生细节。
