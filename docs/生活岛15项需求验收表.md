## 本轮实机输入与存档复核（Godot Web + Chromium）

- **R05 统一交互缺陷修复：** 鸟类互动解锁后，按钮判定曾在玩家远离鸟时提前返回 `false`，因此遮蔽后续乌龟和池塘交互。改为仅在靠近鸟时选择鸟互动，远离时继续检查其他目标。狐狸、乌龟、小鸟、兔子按钮均以真实鼠标点击产生对应可见回复。
- **R11/R14 植物闭环：** 三种植物各自种植、浇水、等待成熟、收获并完成第二轮。各自刷新后保留生长阶段；末轮存档断言要求收获次数 `[2,2,2]`、阶段 `[0,0,0]`。详见交付测试日志 `free-life`。
- **R14 钓鱼：** 开始、取消、重新抛竿、等待咬钩、收竿，连续两次成功捕获；走开会取消抛竿。最终刷新保持鱼获计数和钓鱼空闲状态。
- **存档专项：** 5 个独立浏览器上下文完成 Q001 三板收集、交付、修桥和刷新恢复；含收集第一板后的立即刷新，以及等待后再刷新。游戏内 GameState 与同步镜像先一致，IndexedDB 的完整读取事务随后收敛至同一桥梁状态。旧快照是异步 WebFS→IndexedDB 写入尚未完成时读取到的暂态，不是已加载进度倒退。
- **完整任务输入：** 当前构建上通过真实输入从新存档完成 Q001–Q006 与 Q012；再从实际 Q012 存档完成 Q007–Q011 的材料、建造、摆放及刷新。没有直接改任务完成字段或调用完成函数。完整证据见交付包 `tests/` 与截图。
- **独立回归：** Godot 75/75；桥梁往返 20 轮；21 次显式刷新；移动视口和 PWA 检查；R01 触控模拟。发布候选采用相同 Web 导出 `build/web`。
