# 开发与浏览器预览

本项目以 `/workspace/wonder-isle` 作为云端开发工作区。项目使用 Godot 4.7；云端构建固定使用 Godot 4.7.2。系统里的 `godot` 命令可能指向其他版本，运行预览时应指定正确的可执行文件。

## 一次性环境准备

- 安装 Godot 4.7.2 和对应的 Web export templates。云端环境安装脚本负责下载并校验官方文件。
- 安装 `tools/requirements-web-test.txt` 中的 Python 包，以及 Chromium。
- 项目自带精简后的 Noto CJK 字体子集，即使浏览器没有中文系统字体也可以正常显示。

在云端首次准备或修复依赖时运行：

```bash
bash tools/setup_web_environment.sh
```

## 每次改动后的浏览器验证

```bash
export GODOT_BIN=/tmp/wonder-isle-godot-4.7.2/Godot_v4.7.2-stable_linux.x86_64
export XDG_DATA_HOME=/tmp/wonder-isle-godot-data
export CHROMIUM_PATH=/usr/bin/chromium
python3 tools/run_isolated_tests.py && tools/test_web_preview.sh
```

`run_isolated_tests.py` 会运行全部 72 项 GDScript 状态、运行时和存档回归测试，并把存档与日志放到新的 `/tmp` 目录。`test_web_preview.sh` 会导出 `build/web/index.html`、加上中文启动故障说明，再用 Chromium 实际启动游戏、验证 WebGL2、模拟缺少 WebGL2 的报错分支，并用真实按键和拖拽走完 Q007–Q011 可选任务；它会检查阶段存档、浏览器刷新恢复和绿色拖放提示截图。主线浏览器流程另有 Q001–Q012 实际操作检查。通过后查看截图确认布局和字体。

Web 导出会把 Godot 的启动错误改成中文，并在浏览器缺少 WebGL2 时显示处理步骤。玩家端可使用最新版 Chrome/Edge，在“设置 → 系统”开启“使用图形加速（如果可用）”并重启；也可打开 `chrome://gpu` 或 `edge://gpu` 检查 WebGL2 状态。云端冒烟测试会验证 Chromium 实际创建了 WebGL2 上下文。

新增中文界面文案时，运行 `python3 tools/refresh_cjk_font.py` 更新字体子集。运行项目现有测试时，每个接受 `--test-save-path` 的测试都应传入新的 `/tmp` 临时存档路径。

## GitHub 预览链接

`.github/workflows/web-preview.yml` 会并行运行 72 项 GDScript 回归测试与 Web 构建/Chromium 冒烟测试；浏览器检查通过后即可部署 Pages，回归测试结果会单独报告。PR 会运行检查并上传 Web 构建与截图；向 `main` 或 `work` 推送后会更新 GitHub Pages。仓库需要先在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。部署完成后地址为 `https://zhuwd-dev.github.io/wonder-isle/`。在本地/云端即时改动时，不必等待部署，直接运行上面的命令即可生成并检查当前工作树的浏览器截图。
