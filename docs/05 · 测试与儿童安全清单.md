# 《奇趣小岛》测试与儿童安全清单

版本：V1.0  
用途：原型验收、MVP 回归、试玩与发行前核对

---

## 1. 核心玩法测试

### 启动与新游戏
- [ ] 首次启动可进入小岛。
- [ ] 新玩家能看懂第一个互动目标。
- [ ] 无网络时核心玩法可运行。
- [ ] 返回、退出和重新进入流程正常。

### 交互与收集
- [ ] 可交互对象有明确反馈。
- [ ] 连续快速点击不会重复发奖。
- [ ] 资源达到目标数量后能正确推进任务。
- [ ] 目标错误时提示温和且容易理解。
- [ ] 任务完成后世界状态发生预期变化。

### 建造
- [ ] 可进入和退出建造模式。
- [ ] 可以选择已解锁物品。
- [ ] 合法位置可以放置。
- [ ] 非法位置无法确认放置。
- [ ] 可以移动和移除装饰。
- [ ] 关键建造点不能被错误移动或删除。
- [ ] 放置数据保存后可正确恢复。

### 任务
- [ ] 前置条件生效。
- [ ] 未解锁任务不能提前完成。
- [ ] 完成任务只发奖一次。
- [ ] 已完成任务重新触发不会重复发奖。
- [ ] 任务完成动画不会阻塞后续操作。
- [ ] 任务状态与地图状态一致。

### 存档
- [ ] 首次保存成功。
- [ ] 正常退出再进入后恢复一致。
- [ ] 异常关闭后的数据损失有合理控制。
- [ ] 无效存档不会导致无提示崩溃。
- [ ] 旧版本存档能迁移或安全回退。
- [ ] 存档不包含儿童身份信息。

## 2. 触屏与可用性
- [ ] 关键按钮点击区域足够大。
- [ ] 点击和拖拽不会互相误触。
- [ ] 竖屏/横屏策略已明确。
- [ ] 不同分辨率下 UI 不被遮挡。
- [ ] 支持系统安全区域。
- [ ] 重要信息不只通过颜色区分。
- [ ] 无需快速反应或精准连续操作。
- [ ] 音乐与音效可以分别调节。
- [ ] 退出入口容易找到。

## 3. 儿童试玩流程

### 试玩前
- [ ] 取得监护人知情同意。
- [ ] 向监护人说明测试目的、观察内容和数据处理方式。
- [ ] 不收集与研究无关的身份信息。
- [ ] 如需录像/录音，另行说明用途、访问者、保存期限并取得适当同意；非必要则不录制。
- [ ] 设定清晰的试玩时长与停止方式。

### 试玩中
- [ ] 先给出简短开放式指引，不直接手把手教。
- [ ] 记录卡点、误操作、主动探索和自发创作行为。
- [ ] 不以奖励、礼物或压力诱导孩子继续玩。
- [ ] 孩子表示不想玩时允许立即停止。
- [ ] 不将儿童个体表现用于公开比较。

### 试玩后
- [ ] 先记录行为事实，再写设计推断。
- [ ] 向监护人征求对安全、内容、时长和付费方式的反馈。
- [ ] 删除不再需要的测试记录。
- [ ] 不把 5—8 人的小样本描述成市场总体结论。

## 4. 安全与隐私设计
- [ ] 首版无陌生人聊天、私信、好友和公会。
- [ ] 首版无公开 UGC 上传。
- [ ] 首版无广告、内购和随机付费奖励。
- [ ] 首版不需要账号。
- [ ] 不请求精确位置、通讯录、麦克风或摄像头权限。
- [ ] 不引入未说明的第三方 SDK 或网络请求。
- [ ] 日志不输出个人信息。
- [ ] 素材与第三方依赖均有许可证记录。
- [ ] 退出与家长信息入口易于找到。
- [ ] 游戏不会通过签到惩罚、限时稀有物品或付费加速制造焦虑。

## 5. 中国大陆商业发行前的核对项

此清单是提醒，不构成法律意见。应按正式发行时有效的法律法规、主管部门要求和渠道规则逐项核实。

- [ ] 确认游戏出版审批要求与适用路径。
- [ ] 确认开发、出版、运营主体条件。
- [ ] 确认与出版单位、运营单位的合作要求（如适用）。
- [ ] 确认实名验证、防沉迷和未成年人游戏时长管理要求（如适用）。
- [ ] 确认适龄提示、付费管理和退款处理要求。
- [ ] 确认个人信息保护、儿童个人信息处理规则和监护人同意流程。
- [ ] 确认应用商店审核、隐私标签、权限申报和 SDK 要求。
- [ ] 确认素材版权、字体、音乐、商标和角色授权。
- [ ] 不因首版离线或无内购就自行认定免于出版审批。
