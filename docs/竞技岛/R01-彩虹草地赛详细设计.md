# R01 彩虹草地赛设计草案

定位：6–8 岁单人轻量障碍赛。沿现有画面黄色道路从左下起点到右上彩虹门，绕中央花坛并沿右侧弯道抵达终点。路线坐标以 1280×720 背景空间记录，背景与角色共享变换。路线边缘贴近道路，遇边界停止，不能跨越花坛或中间草地。

比赛依次为准备教学、三秒倒计时、比赛、结算；失焦暂停并清空输入。玩家用摇杆或方向键移动，使用跳跃按钮或空格跳低栏，高木桩留一侧空间绕行。检查点沿路线按前进方向依次通过，全部通过后从正向跨过终点才结算。撞障碍不扣奖励，停下后可立即重试，允许回最近已通过的检查点。计时在倒计时后开始、暂停时停止、结算时停止。重玩清空临时进度并重新倒计时。个人最佳只记录本地匿名时间，不更改生活岛任务。

画面用箭头、旗帜、简短图示提示前进方向、跳跃和绕行。成绩卡展示用时、个人最佳、重玩及返回。星星作为非必需收集，不能阻止完赛。桌面键盘和手机横屏双指均需实际试玩；边界、障碍、检查点、终点应在四种视口逐段验证。所有具体位置、宽度、计时、奖励及正式美术仍需游戏内试玩调整。正式图集不足时标注视觉阻塞。

验收：真实输入完成赛道、重玩及返回；反向测试抢跑、穿越草地、绕过低栏、跳过高桩、检查点和反向终点；原生活岛任务及存档回归。任何一项关键规则失败不得标记通过。

## 当前实现和待校准项目

入口在生活岛左侧石路附近，交互半径 72 个世界单位，完成修桥后开放；进入和退出时释放方向输入及摇杆。入口贴图是独立透明图片，实际遮挡与道路衔接须在多任务状态下验证。

赛道以 1280×720 背景坐标为基准，路线有 31 个折点，逻辑中心按角色脚底偏移，世界宽度变化只平移画面和路线而不拉伸背景。玩家被限制在当前路径段和相邻段的约 48 世界单位半宽内，避免从相邻弯道直接跳段。该参数须按实际图像边缘和角色尺寸反向测试，不能仅凭示意图确认。

倒计时 3 秒，倒数期间禁止移动和计时，结束时清理输入并启动计时。第一、第二路标分别在路径点 10、21，必须由路径前向穿过；回路标只恢复位置，不重置计时。终点须在两个路标均完成后从最后路径段方向穿过。中途刷新返回生活岛并保留生活岛进度，赛道当次成绩不恢复；失焦期间暂停计时及输入。精确计时使用单调时间。

第一处矮栏横贯道路，起跳高度达到阈值才允许穿越；高桩始终阻挡，玩家从右侧绕行；轻碰立即停住且可重试。五颗可选星沿路径放置，每颗每轮至多收集一次，不影响完赛。结算显示本次用时、星数及本地匿名个人最佳，首次或刷新最佳显示鼓励。最佳成绩独立于生活岛存档，试玩与正式使用不同路径和浏览器键；浏览器镜像仅保存有效的更短成绩。重玩清除星数、路线段和检查点并重新倒计时。

教学面板展示移动、跳跃及终点，路牌显示低栏跳跃和高桩右侧绕行。现有碰撞、按钮、布局和音效均须通过实际桌面和触摸试玩核实；现有素材和标记尚未通过正式美术验收。计时、跳跃、落地、碰撞、星星、检查点及终点使用低音量的程序合成短音；实际设备音量与听感尚待验收。
