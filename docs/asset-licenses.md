# 《奇趣小岛》素材许可证记录

状态：阶段 1 初始记录  
更新时间：2026-10-20

## 当前使用情况

本阶段启动场景只使用 Godot 原生节点、纯色和文字占位内容，没有导入外部图片、模型、字体、音乐、音效或动画素材。

因此当前没有需要登记的第三方素材、购买凭证或署名要求。

## 后续登记要求

每项外部或 AI 生成素材在进入项目之前，至少记录：

- 素材 ID 和文件路径；
- 来源页面或生成来源；
- 作者或供应方；
- 许可证或购买凭证；
- 是否允许商业使用；
- 是否允许修改和再分发；
- 署名、链接或其他通知要求；
- 适用版本和使用范围。

不得从其他商业游戏提取素材。未完成授权记录的素材不得标记为最终资源。
