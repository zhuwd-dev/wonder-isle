# 《奇趣小岛》素材许可证记录

状态：持续维护
更新时间：2026-10-30

## 当前使用情况

项目使用 Noto Sans CJK SC 子集字体，以及本项目原创生成的角色、建筑、花圃、池塘和河石插画。角色来源见 `assets/art/characters/README.md`；2026-10-30 生成的场景素材及用途见 `docs/art/scene-art-guidelines.md`。其他未列出的环境和界面绘制仍由项目代码生成。

角色插画没有引用第三方图库或商业游戏素材；项目中的修改、发布和署名要求按图像生成服务条款执行。字体许可证另见 `assets/fonts/OFL.txt`。

## 后续登记要求

每项外部或 AI 生成素材在进入项目之前，至少记录：

- 素材 ID 和文件路径；
- 来源页面或生成来源；
- 作者或供应方；
- 许可证或购买凭证；
- 是否允许商业使用；
- 是否允许修改和再分发；
- 署名、链接或其他通知要求；
- 适用版本和使用范围。
