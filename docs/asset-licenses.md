# 《奇趣小岛》素材许可证记录

状态：持续维护
更新时间：2026-10-28

## 当前使用情况

项目使用 Noto Sans CJK SC 子集字体，以及本项目原创生成的角色插画。生成图已裁切后放入 `assets/art/characters/`，逐张素材来源与角色映射见该目录的 `README.md`。其他环境、道具和界面绘制均由项目代码生成。

角色插画没有引用第三方图库或商业游戏素材；项目中的修改、发布和署名要求按图像生成服务条款执行。字体许可证另见 `assets/fonts/OFL.txt`。

## 后续登记要求

每项外部或 AI 生成素材在进入项目之前，至少记录：

- 素材 ID 和文件路径；
- 来源页面或生成来源；
- 作者或供应方；
- 许可证或购买凭证；
- 是否允许商业使用；
- 是否允许修改和再分发；
- 署名、链接或其他通知要求；
- 适用版本和使用范围。
