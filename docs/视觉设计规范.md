# 奇趣小岛视觉设计规范

## 美术方向

定位为温暖、安静、适合亲子游玩的绘本探索游戏。场景采用柔和的手绘草木色与层叠海岸，角色使用带纸感笔触的原创插画；交互物保持清楚、易识别。避免高饱和荧光色、粗黑边、开发占位框和密集的常驻提示。

## 色彩与材质

- 草地：`#82C77C`；叶片和完成态：`#6C9A65`。
- 河水：`#55B7CA`；岸线：`#F2D39B`。
- 木材：暖棕 `#D5A468`；重要目标：柔和金 `#DBB66E`。
- 界面底色：羊皮纸 `#FFF8E8`；正文：深苔绿 `#294438`；细线和次要文字：灰叶绿。
- 面板采用浅色、细描边、小幅柔影；交互按钮保持足够大的触控区域。

## 信息层级与布局

1. 左上任务卡显示当前阶段、目标句和主线进度。
2. 底部中央提示当前可执行的下一步。
3. 右下按钮执行当前动作，玩家靠近目标后才高亮。
4. 右下托盘只在当前流程需要物品时显示。
5. 右侧未开放区域展示淡化的环境预览和简短解锁条件，不用整块灰色禁用区。

## 动画原则

角色待机使用轻呼吸与小幅摆动；移动使用轻弹步；水面和花叶使用缓慢循环；任务完成用短暂、轻柔的光圈和花瓣。所有动效服务于反馈，不遮挡任务文字和可操作物品。

## 当前落地与后续资产方向

本轮已统一主界面的纸张色 UI、岛屿海岸与路径、锁区预览，并替换玩家及四位伙伴的占位角色。桥、木板、池塘、花圃和道具仍由 Godot 原生绘制；后续制作道具素材时应沿用温暖木纹、柔边石材和绘本植物笔触，避免再引入粗黑框或纯色调试块。
