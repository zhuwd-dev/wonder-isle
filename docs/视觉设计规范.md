# 奇趣小岛视觉设计规范

## 主调

「云海上的手绘奇趣群岛」：把浮空岛冒险地图的清晰结构、东方园林的水岸花木，以及绘本的温柔光色统一起来。场景细节丰富，但可操作对象和下一步目标必须始终容易辨认。

## 场景

- 横向 16:9，左侧主岛、中央溪流与桥、右侧花园岛，沿用现有关卡交互坐标。
- 背景以云海、青绿草地、石阶、苔石、樱花和溪水构成；中央活动空间留白，边缘承载植物和装饰。
- 角色、桥和任务物件以独立图层绘制，背景不预埋任何可交互道具。
- 主色为玉绿、青蓝、暖石金；花朵使用少量珊瑚粉、乳白与浅蓝点色。

## 界面

- 左上羊皮纸任务手记显示阶段、任务目标与进度；底部提示条只说明当前可执行的一步。
- 右下互动按钮与左下圆形移动盘维持固定位置，触屏时有清楚的触控反馈。
- 面板采用暖白纸色、细金边和轻柔阴影；锁区直接展示环境，不再用虚线或空框占位。
- 需要拖放时才出现托盘和落点提示，保持场景的观赏空间。

## 动画

- 花叶、幼苗和角色用缓慢摆动与呼吸表现生命感；溪面有柔和流光，花瓣低速飘过。
- 收集和任务切换使用短暂光圈与粒子，动画不覆盖操作提示，也不改变输入判定。
- 环境循环保持轻、慢、低对比度，避免长期闪烁和分散注意力。

## 素材来源

- `assets/art/environment/floating-garden-bg.jpg`：基于用户提供的园林与农田参考图生成的游戏背景，并裁切到 1280×720。
- `assets/art/characters/`：项目原创角色插画；之后应统一为手绘绘本质感，保留透明底和清楚剪影。
- 任务道具目前由 Godot 原生绘制，后续美术替换需保持坐标、触控区域和落点逻辑分离。
