# Character artwork

The character cutouts in this folder were generated for *Wonder Isle* using OpenAI Image Generation on 2026-10-28, then cropped and resized in this repository.

- `mouse.png` — playable island mouse
- `rabbit.png` — bridge quest rabbit
- `fox.png` — house quest fox
- `turtle.png` — garden quest turtle
- `bird.png` — birdhouse quest bird

These are original generated images, not copied from an existing game or third-party asset pack. They may be modified and used in this project, including commercial releases, under the image-generation service terms. The original prompt sheets are not stored in the project; the cropped game-ready assets are the source of truth.
