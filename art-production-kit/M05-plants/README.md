# M05 三种植物：独立成长与收获状态

**当前原图：** `current-art/` 中为当前游戏使用的 `assets/art/plants/` 状态 PNG（幼苗、成长、开花、成熟可收获及解锁状态）。**地图截图：** `gameplay-reference/turtle-garden.jpg`。

- 当前候选的这些图是共用状态资产，不等同于三种植物各自完整的正式成长图；正式素材必须有三种独立轮廓。
- 每种植物至少种子、幼苗、成长、成熟/开花/结果、收获后五态；叶形、株型、花/果轮廓清楚不同。
- 建议每态 128×128 或 256×256 RGBA 透明；根部锚点 `(64,116)` 或 `(128,232)` 固定；阶段过渡 0.25–0.45 秒；不需要每态高帧循环。
- 接入：`assets/art/plants/`、`assets/art/production-art.json`、`scripts/visual/scene_art_registry.gd` 与 `scripts/boot/main.gd` 种植绘制；保存种类和阶段字段。
- 验收：每类逐项种植→浇水→成长→收获→再种；刷新前后状态一致；不同底色上检查透明边缘与根部位置。

**生成提示词：**
> 以附件花圃截图及当前状态图为风格参考，设计三种明显不同的童话植物，分别有独立叶形、枝干和花/果轮廓。每种输出种子、幼苗、成长、成熟开花/结果、收获后五个阶段。柔和手绘绘本风，逐个植物独立透明RGBA、单体居中；建议128×128或256×256，所有阶段根部锚点固定(64,116)或(128,232)。不要盆器、背景、投影、文字、不透明底色、彩边或仅靠同一造型换色区分。
