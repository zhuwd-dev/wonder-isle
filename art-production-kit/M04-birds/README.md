# M04 鸟类：停留、飞行与回应

**当前原图：** `current-art/bird.png`（`assets/art/characters/bird.png`，466×595 RGBA）；同目录含 `birdhouse-complete.png`。**地图截图：** `gameplay-reference/life-island-map.jpg`。

- 保留鸟喙、羽色、眼睛、比例和鸟屋风格；鸟爪落点固定，飞行起落不变形。
- 停留/待机每方向 2–4 帧；短飞行和落栖循环至少 6 帧；打招呼/任务回应 4–6 帧；建议 8 FPS。
- 单帧 512×512 RGBA 透明；爪部锚点 `(256,440)` 固定（飞行时可由动画资源额外记录偏移）；边缘 ≥24px。
- 接入：`assets/art/characters/bird/`、`assets/art/production-art.json`、`scripts/boot/main.gd` 鸟屋互动响应。
- 验收：玩家打招呼后鸟有清晰回应；飞离/落栖不闪现，刷新不会重置鸟屋进度。

**生成提示词：**
> 参考附件的小鸟和鸟屋截图，保持羽色、鸟喙、眼睛和柔和绘本风格。制作停留待机、眨眼、面向玩家回应、短距离振翅飞行并回到栖木的动作。待机2–4帧，飞行至少6帧循环，回应4–6帧，8FPS。逐帧独立512×512透明RGBA，爪部落点锚点固定(256,440)，透明边缘至少24px。禁止羽色漂移、翅膀糊成一团、鸟屋/树枝背景、文字、投影和拼格。
