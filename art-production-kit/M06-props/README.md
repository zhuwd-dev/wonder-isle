# M06 任务道具与钓鱼素材

**当前原图：** `current-art/` 包含木板、河石、种子袋、浇水壶及建筑素材；均来自当前游戏的 `assets/art/`。**地图截图：** `gameplay-reference/life-island-map.jpg`。

- 保留地图已有木板、河石等融合良好的任务道具，避免重做已合格资源。
- 当前清点没有独立鱼竿、鱼线、鱼漂、水面波纹和鱼类 PNG；这些需新制：手持鱼竿、细鱼线（可程序绘制）、清晰鱼漂、轻波纹、3 种收获鱼插画。
- 单件 256×256 RGBA 透明；鱼竿握持锚点 `(128,210)`，鱼漂水面锚点 `(128,128)`；结果鱼约角色高度 0.25–0.4 倍；鱼竿/漂反馈轻循环 4–6 FPS。
- 接入：现有任务资源 `assets/art/props/` 与 `assets/art/environment/`；新鱼素材放 `assets/art/fishing/` 并在 `assets/art/production-art.json` 注册，再接入 `scripts/boot/main.gd` 钓鱼状态。
- 验收：抛竿、鱼线、漂、水波、收竿提示、结果、退出和再次钓鱼均可见；检查花圃/鱼塘重叠交互优先级。

**生成提示词：**
> 参考附件中的游戏地图及已有木板、河石和任务道具，制作匹配奇趣小岛柔和手绘自然风格的儿童钓鱼物件：小型木鱼竿、细线、彩色木塞鱼漂、轻盈水波和三种可爱淡水鱼结果图。分别输出独立透明背景PNG RGBA，建议256×256，鱼竿握持锚点(128,210)，鱼漂接触水面锚点(128,128)，鱼线可由程序单独绘制。无文字、无容器、无背景，不要粗糙几何占位。
